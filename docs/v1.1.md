# V1.1 changes

V1.1 improves the timetable setup and makes the main actions easier to reach.

## Group selection

- Setup now saves a group choice per subject, scoped by division. This prevents a
  group chosen for one subject from unintentionally including lessons from
  another subject.
- After setup, students can review their choices on a confirmation page and
  change any group that has alternatives before generating the timetable.
- The timetable view includes an edit-groups action that reopens this review
  screen without requiring the whole setup flow to be repeated.
- Restoring cookie or shared-link selections now drops invalid or outdated
  subject/group pairs instead of rendering them.

## Timetable actions and feedback

- Edit groups, copy link, download, and theme controls are compact icon actions
  above the timetable.
- Copying a link works with the Clipboard API and includes a browser fallback
  for mobile or restricted clipboard environments.
- Successful and failed copy operations, plus downloads, show a brief status
  message.

## Validation and coverage

- Shared-selection validation now requires non-empty string selection and group
  identifiers.
- Tests cover filtering a selected group to the specific subject represented by
  a subject-scoped selection key.
